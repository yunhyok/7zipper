# 7Zipper v0.1.4

전체 진행률 표시와 압축 옵션의 성능 설정 스크롤 개선.

- **전체 진행률:** 폴더별 압축·여러 압축 파일 해제에서 대기 중인 항목까지 포함. 전체 진행률, 완료 개수, 현재 압축 파일 진행률을 구분하여 표시.
- **진행률 기준:** 여러 압축 파일 작업은 파일별 진행 비율의 평균. 화면에 `압축 파일 수 기준` 명시. 여러 파일·폴더를 하나로 압축할 때는 기존 전체 바이트 기준 유지.
- **완료 처리:** 결과 파일 저장이 끝난 작업만 완료 개수에 반영. 취소·실패를 전체 완료로 표시하지 않음.
- **성능 설정:** 옵션 화면 하단의 스크롤 여유 확보. 성능 설정을 펼치면 입력란을 보이도록 이동하고, 작은 창에서 메모리 설정 설명 줄바꿈.

[검증 기록](https://github.com/yunhyok/7zipper/blob/v0.1.4/docs/validation-v0.1.4.md)

- 설치판: `7Zipper-Setup-0.1.4-x64.exe`
- 포터블: `7Zipper-0.1.4-win-x64-portable.zip`
- 무결성 확인: `SHA256SUMS.txt`

기본 설치 경로 Program Files 및 설치 위치 선택 유지. 코드 서명 미적용. Windows 11 탐색기 메뉴는 **더 많은 옵션 표시**에서 사용.
