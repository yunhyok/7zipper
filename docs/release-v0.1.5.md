# 7Zipper v0.1.5

안정성 오류 수정 및 UI/UX 개선.

- **오류 수정:**
  - 드래그 복사 준비 중 마우스를 놓았을 때 마우스 캡처가 남아 취소 버튼을 누를 수 없던 문제 수정.
  - 탐색기 오른쪽 클릭 메뉴가 `.7z.002` 등 2번 이후 분할 7z 조각도 인식하도록 수정.
  - 압축 파일 내부 폴더 탐색·선택의 대소문자 불일치 및 폴더 이동 후 정렬 화살표 잔류 문제 수정.
  - 여러 압축 파일 작업 완료 시 전체 100%와 완료 개수 표시 불일치 레이스 컨디션 수정.
  - 읽기 전용 대상 파일 덮어쓰기 및 읽기 전용 임시 하위 폴더 정리 실패 방지, 예약 장치명·끝 점(`..`) 폴더 이름 정제.
  - 새 압축 대화상자에서 기존 분할 볼륨·폴더 충돌, 드라이브 루트, `64 MiB` 미만 메모리 한도 등 사전 검증 보강.
  - 작업 취소 타이머 및 드래그 임시 정리 태스크 누수 방지, `PrimaryAction` 버튼 호버 색상 오류 수정.
- **UI/UX 개선:**
  - 이름 충돌 대화상자에 **이후 모든 같은 이름 항목에 적용** 옵션 추가.
  - 새 압축·압축 풀기·암호 입력 창에 **암호 표시** 토글 추가.
  - 새 압축 수준에 **저장만 (무압축)** 옵션 지원 및 파일 목록 드래그앤드롭·`Delete` 키 제거 추가.
  - 작업 완료 후 탐색기로 바로 이동하는 **폴더 열기** 버튼과 드래그앤드롭 안내 오버레이 추가.
  - 창 제목에 열린 압축 파일명 표시, 상태 표시줄에 원본·압축 크기 및 선택 항목 크기 합계 표시, 검색어 지우기(`×`) 버튼 및 `Ctrl+T`·`F5`·`Alt+↑` 단축키 지원.
