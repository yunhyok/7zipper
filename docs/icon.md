# 7Zipper icon

Created for this project using the built-in image generation tool. The original master is `assets/7zipper.png` (RGBA); `assets/7zipper.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel Windows icon images. ICO conversion preserves the generated transparent artwork.

Prompt: A finished desktop application icon for 7Zipper: two compact charcoal archive blocks joined by a crisp blue zipper, a bold readable silhouette, rounded geometry, restrained dimensional lighting, palette #202226/#2b2e34/#386cb0/#8fc1ff, transparent background, no text, letters, numbers or existing logos. Centered with transparent padding, suitable for small Windows taskbar sizes.
