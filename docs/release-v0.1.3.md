# 7Zipper v0.1.3

탐색기 아이콘·요청 처리 보완과 실제 배포 앱 검증 강화.

- **탐색기 아이콘:** 상위 메뉴에 아이콘을 명시적으로 등록. 별도 ICO 대신 실행 파일에 내장된 아이콘 사용. 250% 배율의 40px 아이콘 확인.
- **요청 전달:** 종료를 기다리는 창을 건너뛰어 새 탐색기 요청 처리. 관리자 권한·일반 권한과 Windows 세션별로 단일 인스턴스 통신 분리.
- **폴더별 압축:** 기존 분할 볼륨이 있을 때 병렬 작업이 같은 출력 이름을 선택하던 문제 수정. 기존 볼륨 보존과 두 압축본의 내용 확인.
- **검증:** 실제 배포 앱의 7z·ZIP 압축, 여기에 풀기·스마트 풀기를 CI에서 실행. 설치·제거 시험은 폐기 가능한 Windows 환경으로 제한.

[검증 기록](https://github.com/yunhyok/7zipper/blob/v0.1.3/docs/validation-v0.1.3.md)

- 설치판: `7Zipper-Setup-0.1.3-x64.exe`
- 포터블: `7Zipper-0.1.3-win-x64-portable.zip`
- 무결성 확인: `SHA256SUMS.txt`

설치 경로 선택과 Program Files 기본 경로 유지. 코드 서명 미적용. Windows 11 새 컨텍스트 메뉴는 미제공이며 **더 많은 옵션 표시**에서 사용.
