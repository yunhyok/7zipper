# 7Zipper v0.1.1

v0.1.0의 오류 수정 릴리스. 압축 형식·설정 항목·설치 구성은 그대로.

- **USB 메모리 등 FAT32·exFAT 볼륨:** 인터넷에서 받은 압축파일을 이 볼륨에 풀 때 실패하던 오류 수정. 영역 표시는 대체 데이터 스트림을 지원하는 볼륨에서만 전달.
- **ZIP 파일명:** UTF-8 표시가 없는 이름의 글자 깨짐 수정. Unix·macOS 작성본은 UTF-8, 그 외는 Windows OEM 코드페이지(한국어 Windows는 CP949)로 해석. 7-Zip과 같은 기준.
- **출력 이름:** 같은 이름의 분할 압축과 번호가 붙은 압축파일이 함께 있으면 압축을 끝낸 뒤 저장에 실패하던 오류 수정. 비어 있는 다음 번호로 저장.
- **끌어서 내보내기:** 마우스 왼쪽·오른쪽 단추를 바꾼 설정에서 끌기가 항상 취소되던 오류 수정.
- **화면 응답:** 압축 풀기의 마지막 파일 이동을 화면 스레드 밖에서 실행. 파일이 많은 압축파일에서 창이 멈추던 현상 완화.

- **설치판:** `7Zipper-Setup-0.1.1-x64.exe`
- **포터블:** `7Zipper-0.1.1-win-x64-portable.zip`
- **무결성 확인:** `SHA256SUMS.txt`

v0.1.0 위에 설치판을 실행하면 같은 위치로 업데이트. 탐색기가 셸 DLL을 사용 중이면 Windows 재시작 후 교체.

Windows CI에서 빌드, 관리 코드·프로세스 통합 시험, 셸 자동 시험, 네이티브 회귀 시험 통과. 추가한 시험: 영역 표시 전달, 출력 이름 충돌, UTF-8 표시 없는 ZIP 이름.

자동 시험 환경에서 실행하지 못한 항목: 한국어 Windows의 CP949 이름 해석, 단추를 바꾼 마우스의 실제 끌기. 두 항목은 Microsoft 문서·7-Zip 소스와 대조한 코드 검토로만 확인. v0.1.0의 미검증 항목도 그대로: [검증 기록](https://github.com/yunhyok/7zipper/blob/v0.1.1/docs/validation.md).

공식 7-Zip 프로젝트와 별개의 MIT 오픈 소스 프로그램.
