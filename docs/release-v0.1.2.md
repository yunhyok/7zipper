# 7Zipper v0.1.2

구형 ZIP 파일명 호환성 수정과 마우스 단추 교체 설정의 드래그 검증.

- **CP437 ZIP 파일명:** 한국어 Windows에서 `é.txt`, `ä.txt` 등이 잘못 해석되어 열리지 않던 문제 수정. 시스템 OEM 코드페이지에서 유효하지 않은 바이트는 CP437로 다시 해석.
- UTF-8 표시·유니코드 확장 필드 우선순위 유지. 정상 CP949 한글 이름도 정확한 이름과 내용으로 해제.
- 두 코드페이지에서 모두 유효한 구형 이름은 기존처럼 시스템 OEM 코드페이지 우선. 코드페이지 수동 선택은 미제공.

- **설치판:** `7Zipper-Setup-0.1.2-x64.exe`
- **포터블:** `7Zipper-0.1.2-win-x64-portable.zip`
- **무결성 확인:** `SHA256SUMS.txt`

기존 설치 위치에 업데이트 가능. 탐색기가 셸 DLL을 사용 중이면 Windows 재시작 후 교체.

코드 서명 미적용. Windows 11 새 컨텍스트 메뉴는 미제공이며 **더 많은 옵션 표시**에서 사용.
