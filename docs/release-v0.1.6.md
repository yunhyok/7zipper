# 7Zipper v0.1.6

ZIP 파일을 7z 형식으로 변환하는 기능 추가.

- **ZIP → 7z 개별 변환:** 단일 ZIP은 물론 여러 ZIP 파일을 선택했을 때 각각 별도의 `.7z` 파일로 1:1 변환(병렬 처리 및 전체·현재 진행률 표시).
- **최대 압축률 기본 적용:** `7z` 변환 시 최대 압축(`Level 9`, LZMA2)을 기본 옵션으로 적용하며, 옵션 창에서 압축 수준·저장 폴더·분할 크기·암호·원본 삭제 여부를 자유롭게 변경 가능.
- **탐색기 우클릭 메뉴 연동:** 파일 탐색기에서 1개 이상의 `.zip`(또는 `.z01` 등 분할 ZIP) 파일을 선택하고 **7Zipper → 7z로 변환**을 클릭하면 즉시 최대 압축으로 각각 `.7z` 변환 실행.
- **앱 툴바 및 단축키 지원:** 메인 창 툴바의 **7z 변환** 버튼(`Ctrl+7`)으로 열린 ZIP 또는 여러 ZIP 파일(파일 선택·드래그앤드롭)을 손쉽게 변환.
- **데이터 보호 유지:** 기존 `.7z` 파일은 덮어쓰지 않고 새 이름으로 생성하며, 원본 ZIP은 기본 유지(선택 시 변환 완료 후 삭제), Mark of the Web(`Zone.Identifier`) 전파 및 암호화 ZIP 비밀번호 프롬프트 지원.
